## Descrição do projeto

Este repositório cataloga um conjunto de regras e boas práticas para serem utilizadas em diferentes tipos de projetos. As regras estão organizadas em pastas que fazem referência ao **tipo principal de projeto** (por exemplo, back-end, front-end, firmware, etc.), facilitando a escolha e a reutilização conforme o contexto.

O objetivo é oferecer um ponto de partida padronizado para configuração de ambientes, documentação, segurança, logs, dependências e demais aspectos recorrentes em projetos de software e firmware.

## Como utilizar

1. Escolha o tipo de projeto ou adapte as regras mais adequadas ao tipo de projeto que você deseja criar.
2. Copie a pasta **`.windsurf`** deste da pasta do tipo de projeto deste repositório para a raiz do seu novo projeto.
3. Ajuste arquivos e regras conforme as necessidades específicas do projeto (por exemplo, seleção de linguagens, frameworks ou políticas internas).

Após isso, o seu projeto poderá aproveitar diretamente as configurações e orientações definidas nas regras deste repositório.
